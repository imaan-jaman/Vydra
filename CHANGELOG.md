# Changelog

All notable changes to Vydra will be documented in this file.

## [1.0.0] - 2024-01-01

### Added
- Initial release
- yt-dlp integration for 1000+ websites
- Video and audio downloads
- Material Design 3 UI
- Light, Dark, and AMOLED themes
- Android Share Target
- Foreground service with progress notifications
- Download history
- Search with filters
- Settings screen
