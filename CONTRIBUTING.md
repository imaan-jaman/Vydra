# Contributing to Vydra

Thank you for your interest in contributing to Vydra!

## Getting Started

1. Fork the repository
2. Create your feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Development Setup

1. Install Android Studio latest stable
2. Clone your fork
3. Build and run on device/emulator (API 26+)

## Code Style

- Follow Kotlin coding conventions
- Usektlint and detekt
- Write meaningful commit messages
- Keep functions small and focused
- Document public APIs

## Pull Request Guidelines

- Reference any related issues
- Include screenshots/video for UI changes
- Ensure the app builds without errors
- Add tests for new functionality when possible

## Reporting Issues

- Use GitHub Issues
- Include device model, Android version, and app version
- Provide steps to reproduce
- Attach screenshots if applicable
